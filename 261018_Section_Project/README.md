# 손과 초록색 공의 목표 도달 게임

## 파일 구조

- **goal_delivery.py**: 카메라로 초록색 공과 손을 인식하고 목표 도달 여부를 판단하는 게임 코드입니다.
- **README.md**: 프로젝트 설명 및 실행 방법을 정리한 파일입니다.

## 실행 방식

VS Code에서 `goal_delivery.py`를 실행합니다.

카메라에 초록색 공과 손을 비추고, 공을 손 가까이에 둔 상태로 화면의 목표를 1 → 2 → 3 순서로 이동시킵니다. 목표 위치에서 일정 시간 유지하면 점수를 얻고 다음 목표로 넘어갑니다.

- **r**: 게임 초기화
- **q**: 게임 종료
- **Green Ball Mask**: 초록색 공의 검출 결과 확인

## 창의성 및 확장성

### 아이디어 설명

수업에서 학습한 객체 검출, 객체 추적, 손 인식 기술을 결합한 게임입니다. 단순히 공의 위치만 인식하는 것이 아니라 손과 공의 거리를 함께 판단하여 사용자의 움직임을 게임에 반영했습니다.

### 구현한 내용

- **영상 처리**: GaussianBlur와 CLAHE를 적용하여 영상을 보정합니다.
- **공 검출**: LAB 색공간과 색상 분할, 모폴로지 연산으로 초록색 공의 위치를 검출합니다.
- **객체 추적**: 칼만 필터로 공의 움직임을 추적하고 일시적으로 검출되지 않을 때 위치를 예측합니다.
- **손 인식**: MediaPipe로 손 관절을 검출하고 손가락 끝과 공 사이의 거리를 계산합니다.
- **게임 기능**: 공과 손의 위치를 바탕으로 목표 도달 여부를 판단하고 점수와 진행 상태를 화면에 표시합니다.

### 확장성

- 목표 위치, 개수, 크기 등을 변경하여 난이도를 조절할 수 있습니다.
- 여러 색상의 공을 구분하여 색상별로 다른 목표를 부여할 수 있습니다.
- JSON으로 점수와 게임 기록을 저장하여 결과를 비교하는 기능을 추가할 수 있습니다.

## 기타 참고 사항

- **구현 기준**: `01_Linux-and-Python.ipynb`, `02_Computer-Vision.ipynb`에서 학습한 내용을 바탕으로 구현했습니다.
- **실행 환경**: Jetson Nano의 Ubuntu 환경에서 USB 카메라와 GStreamer의 YUYV 입력 방식을 사용합니다.
- **AI 활용 및 본인 기여**: 본인은 프로젝트 주제 선정, 핵심 기능 구성, 게임 진행 방식과 성공 조건을 결정했습니다. 수업 자료를 바탕으로 USB 카메라 입력 방식과 코드 구조를 검토하고, 실행 과정에서 발생한 오류를 확인하며 수정 방향을 정했습니다. ChatGPT는 코드 구현 보조, 오류 해결 방법 탐색 및 README 작성에 활용했습니다.
- **검증 상태**: Windows에서 라이브러리 설치 및 불러오기를 확인했으며, Jetson Nano에서 실제 카메라를 이용한 실행은 아직 검증하지 못했습니다.
- **한계점**: 조명과 배경색에 따라 공 검출 정확도가 달라질 수 있으며, 손과 공의 거리는 실제 접촉이 아닌 화면상의 2차원 거리를 기준으로 판단합니다.
